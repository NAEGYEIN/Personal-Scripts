# ChatGPT Tweaks Privacy Policy

Last updated: 2026-10-27

ChatGPT Tweaks is a browser extension that operates on `https://chatgpt.com/*` to improve the ChatGPT web interface and provide user-facing convenience features.

## Data handled

ChatGPT Tweaks may locally handle the following categories of data only when necessary to provide its features:

- **Website content** on `chatgpt.com`, such as interface text, links, buttons, model selector state, composer state, and attachment UI state.
- **User activity** directly related to extension features, such as clicks, paste events, scrolling, focus/input/composition state, and other interaction events needed to keep interface enhancements and model-lock behavior safe.
- **Clipboard file/image data** contained in a paste event when the user pastes a file or image into the ChatGPT composer. The extension uses those bytes in browser memory to create a ZIP attachment.

The extension does not intentionally read or collect passwords, authentication tokens, payment information, health information, location, browsing history, or personal communications.

## How data is used

Data is used only to provide the extension's user-facing features, including:

- ChatGPT layout and link enhancements.
- Chat/Work surface detection.
- Model-selection assistance.
- Clipboard file/image to ZIP attachment conversion.
- Diagnostics requested by the user.

## Collection, transmission, and sharing

ChatGPT Tweaks does not transmit user data to the extension developer or to any developer-operated server.

The extension has no analytics backend and no advertising backend.

The extension does not sell user data and does not transfer user data to third parties for advertising, creditworthiness, lending, or unrelated purposes.

When the user chooses to attach or send content through ChatGPT, that content is handled by ChatGPT/OpenAI under the user's existing relationship with that service. ChatGPT Tweaks does not control OpenAI's processing or retention.

## Storage and retention

Extension settings may be stored locally in the browser.

Clipboard file/image bytes used for ZIP creation are processed in browser memory for the time needed to create the ZIP attachment. ChatGPT Tweaks does not create its own persistent copy of those bytes.

## Remote code

ChatGPT Tweaks does not download or execute remote JavaScript or WebAssembly. Executable code is included in the extension package.

## Chrome Web Store Limited Use

ChatGPT Tweaks's use of information received from Chrome APIs and website access complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Data is used only to provide or improve the extension's single purpose and user-facing features. It is not used for personalized advertising, is not sold, and is not made available for human review except where required by law, security, or explicit user-directed support.

## Scope

The extension is designed to operate only on `https://chatgpt.com/*`.
