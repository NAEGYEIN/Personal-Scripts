# DCInside-Optimizer

현재 기준본: **v1.3.1**

DCInside용 Tampermonkey userscript.

## 주요 기능

- 레이아웃 및 반응형 폭 보정
- 게시물 클릭을 방해하는 요소 제거
- 갤러리 즐겨찾기 저장·이름순 정렬
- 이미지 댓글/디시콘 숨김
